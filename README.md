- Netflix Movies & TV Shows Analysis

Análisis exploratorio de los datos públicos de Netflix (2008–2021).

- Objetivo
Explorar cómo ha evolucionado el catálogo de Netflix en el tiempo, por país, tipo de contenido y otras variables.

-- Dataset
Fuente: Kaggle – Netflix Movies and TV Shows  
Periodo: 2008–2021  

-- Herramientas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

-- Estado del proyecto
Actualmente en fase de limpieza de datos y análisis exploratorio inicial (EDA).
